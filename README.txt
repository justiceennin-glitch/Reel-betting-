REEL BETTING MOBILE WEBSITE DEMO
Files: index.html, style.css, script.js.

Features inspired by your screenshots:
- Red top bar, Join Now and Login demo buttons
- Dark mobile sports interface and fixed bottom navigation
- Sports shortcut navigation and featured match cards
- League filters and sample 1/X/2 odds buttons
- Live match centre placeholder
- Virtual sports / games tiles
- Sample football codes section
- Responsive layout for mobile phones

IMPORTANT:
This is a front-end design demo. Sample odds/fixtures are not live or verified. No accounts, betting, deposits, withdrawals, payment handling, or real gambling games are implemented. For live data, connect a legitimate sports-data API. Real-money gambling needs proper legal/licensing review and secure backend work before launch.
HOW TO PREVIEW: Extract the ZIP and open index.html in a browser.
HOW TO PUBLISH: Upload the three website files to your hosting provider.

DEMO WALLET ADDITION
- Wallet section shows a GHS demo balance.
- Add demo funds and withdraw demo funds to test the interface.
- Transactions are stored in this browser using localStorage.
- This is not a real wallet. It cannot receive money, process Paystack payments, or send withdrawals.
- Browser-local demo data is not secure and should not be used for real customer balances.
